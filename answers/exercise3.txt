Exercise 3 - Ubuntu 101

The previous Exercise 2 container was removed with `--rm`, so I started a new Ubuntu container for this exercise.

PS C:\Users\Student\Desktop\part12> docker container run -d --name part12-exercise3-ubuntu ubuntu sleep infinity
742a2ab12f1fa08f2f15eafc35cfd05f7c160044dd967d6fe215535f09eb5cb8

Nano was installed in the container. This command runner does not provide an interactive Docker TTY, so Nano was opened using Ubuntu's `script` pseudo-terminal. The editor screen was suppressed; the file was checked after Nano saved and exited.

Commands run inside Ubuntu:

mkdir -p /usr/src/app
touch /usr/src/app/index.js
{ sleep 2; printf "console.log('Hello World')"; sleep 1; printf '\017'; sleep 1; printf '\r'; sleep 1; printf '\030'; } | TERM=xterm script -qec 'nano /usr/src/app/index.js' /dev/null >/dev/null 2>&1

The text entered in Nano:

console.log('Hello World')

Nano exited with status 0.
